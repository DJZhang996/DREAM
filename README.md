# DREAM (Updating)
DREAM identifies condition-specific microenvironments by explicitly linking spatial domains to clinical phenotypes
![image text](https://github.com/DJZhang996/DREAM/blob/main/Fig1.jpg)
## Tutorials and reproducibility
We provided codes for reproducing the experiments of the paper "DREAM identifies condition-specific microenvironments by explicitly linking spatial domains to clinical phenotypes ", and comprehensive tutorials for using DREAM. Please check [the tutorial website](https://dream-tutorial.readthedocs.io/en/latest/) for more details.
